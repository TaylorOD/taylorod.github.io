# Widget settings

The header shows the saved pet name and capitalized stage beside the character picker. Care quality sits below the egg.

The bottom Settings disclosure holds Vacation, LCD scanlines, Sound, the original family E ink theme, restart, file backup tools, the care guide, memories and credits. Save status stays on the same line as Settings. Close settings returns focus to its summary.

Embedded games hide their old gear. Standalone games retain it. Commands travel over the existing private frame channel and only known controls are allowed. Restart still asks for confirmation. File imports still preview the replacement and preserve a recovery copy. Pasted saves are removed.

Validation covers configuration types, allowed commands, disabled controls during switching, desktop and mobile layout, Vacation updates and sound preference updates.
