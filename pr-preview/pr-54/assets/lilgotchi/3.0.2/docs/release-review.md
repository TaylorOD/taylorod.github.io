# Release notes

## 3.0.2

Adds the public npm package and a package link beside GitHub. The character guide has a separate back link and logo, with Gen 1 and Gen 2 at the end of the family list.

## 3.0.1

The homepage uses one full width column, with setup instructions inside the settings box. Pet colors live in the game Settings and can be changed separately for each family. Gen 1 now starts with a sage handheld. Dropdown arrows have more room, and the Try again button is centered with space above the divider.

## 3.0

Gen 1 now uses the P1 source sprites. Gen 2 adds the P2 family with its own save. All 26 characters from the source collection are included, with regional and hidden forms using adapted growth paths.

The 267 automated checks pass, including family saves, growth paths and sprite bounds. Browser review covered the character guide, hatching, feeding, family switching, a guessing game, the phone layout and a crowded adult screen. Version 3.0.0 was released with explicit Start pet controls, separate family colors and the curved keychain.

## 2.0

Seven new games: Get, Bump, Heading, Memory, Flag, Sprint and Hoops. The guessing game stays and now shows clear left and right poses.

Release approved by Taylor on November 9, 2026. Automated checks cover the game rules, rewards, cancellation and pixel bounds. All seven games were exercised in a mobile browser, with a separate desktop review of the picker, Bump, Memory and Sprint. Physical device, screen reader, audio listening and longer balance sessions are still needed. See the [review checklist](../design/games/release-checklist.md).

## 1.2

Inactive pets keep their progress without growing or sending notifications. Slice has a lighter shell and display. The launcher is a little smaller, with an inset care badge.
## 1.2.1

The guessing game now shows the answer with a left or right pose before the result reaction. Every hatched pet has both poses. Round timing, odds and rewards stay the same. Closing or restarting a game cancels its pending reactions.

Checked all four families in the browser and both answer directions at desktop and mobile sizes. The 156 automated checks pass. This patch was approved for release before 2.0.

## 1.1

A bigger pet button, a logo option and care counts across your started pets. Open the needs list to jump to the pet that needs you. Notifications can be turned off in the setup tool.


## 1.0

Four families. A little game for your website. Local saves, optional sound, Vacation and a one line install.

The [character guide](characters.md) shows every stage, adult branch and special elder.

[Download it](https://github.com/TaylorOD/lilgotchi/releases/latest) or [add it to your site](install.md).

## Checked

Automated checks cover care, evolution, saves, expressions and keeping pets inside the screen. The game was also checked in Chrome at desktop and mobile sizes.
