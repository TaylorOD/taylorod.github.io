# A named release

Publish an immutable source tag and a built zip on GitHub Releases after the focused source PRs pass and merge. The archive contains the runtime and installation examples, not development tests or original source fixtures. Landing download points to that release asset instead of a moving branch archive.

Keep the installed asset directory compatible with existing embeds. Save schema remains version 1. Release notes list intentional behavioral differences and verification limits. Check the downloadable archive and both hosted copies after publication.
