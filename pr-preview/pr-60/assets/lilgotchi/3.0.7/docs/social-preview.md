# Social preview

Use [social-preview.png](assets/social-preview.png) for the GitHub repository preview. It is 1280 × 640 pixels and under 1 MB.

Open [repository settings](https://github.com/TaylorOD/lilgotchi/settings), find **Social preview**, choose **Edit**, then **Upload an image**. Select the PNG and save the crop if GitHub asks. Committing the image does not set this repository setting.

The image follows the site's dark background and mint accents, with Slice, Cypunk and Lilgotchi based on the existing README character screenshot. It is promotional artwork, not a screenshot of the app.

Created with the built in image generator using `pr-screenshots/readme-three-characters.png` as a reference, then resized to GitHub's recommended dimensions.

## Art direction

Create a polished landscape social preview for lilgotchi. Use a near black background, white lowercase title and mint subtitle. Show the mint gray Slice handheld, dark teal Cypunk handheld and buttery yellow Lilgotchi handheld with their recognizable pixel characters. Keep the layout spacious and all content inside a 40 pixel margin.

Text: “lilgotchi”, “A little pixel pet for your website.”, “github.com/TaylorOD/lilgotchi”.

Use small white GitHub and npm logos in the lower left. Keep the background plain and the handheld shells matte. Keep the three original families. Leave out care panels, stats and third party characters.
