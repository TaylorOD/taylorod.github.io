# lilgotchi Cyberpunk character family

Cyberpunk starts as a binary seed and grows into a small neon machine. Its lifecycle should feel like a system booting, developing a body and taking a different adult form based on care.

## Proposed forms

| Original identity | Cyberpunk form | Shape and distinguishing detail |
| --- | --- | --- |
| `egg` | Binary Seed | Rounded capsule outline containing a few readable 0 and 1 pixels. Two stable boot frames |
| `babytchi` | Bit | Tiny square core with two bright eyes and short feet |
| `marutchi` | Byte | Wider terminal body with a simple antenna |
| `tamatchi` | Runner | Slim upright bot with a clean visor and two legs |
| `kuchitamatchi` | Glitch | Asymmetric bot with one bent antenna and uneven legs |
| `mametchi` | Sentinel | Tall balanced bot with a broad visor and square shoulders |
| `ginjirotchi` | Courier | Compact rounded bot with wheel shaped feet |
| `maskutchi` | Ghost | Hood shaped shell around a narrow face panel |
| `kuchipatchi` | Tank | Wide low body with short tread shaped feet |
| `nyorotchi` | Wire | Small head above a long flexible cable body |
| `tarakotchi` | Scrap | Boxy patched body with mismatched arms |
| `oyajitchi` | Mainframe | Secret Ghost evolution with a compact crown of antennae |

Names are proposed display labels. Retain the original gameplay identities internally. The binary seed is a deliberate readable icon, not random noise or a fast flashing screen.

## Art direction

Use dark navy, cyan, magenta and a pale highlight. A dark outline or bright edge must separate the body from both light and dark supported screens. Give each adult a different silhouette. Do not rely on changing one visor pixel to distinguish evolution outcomes.

Use hard pixel edges. Avoid blur and glow filters on the logical display. If a glow is needed in the outer shell, it must not soften the game artwork. Antennae, cables and feet count toward the full sprite bounds.

## Reactions

| State | Cyberpunk treatment |
| --- | --- |
| Egg idle and hatch | A few binary cells alternate, then the shell opens into Bit at the original hatch moment |
| Idle | Small leg or body motion. Antennae remain attached |
| Happy and game win | Raised arms and bright visor expression |
| Sad and game loss | Lowered visor and relaxed antenna |
| Eat and refuse | Small face panel motion or head turn at the original duration |
| Sleep | Dim closed visor with the shared sleep effect |
| Sick and attention | Readable warning expression plus original status effects |
| Evolve | New body replaces the previous one at the original transition |
| Death and restart | Preserve grave and restart flow. Restart returns to Binary Seed |

Cover every original frame key and composed reaction. Shared symbols remain recognizable and never replace care information with decorative code. Reduced motion uses a stable binary frame and removes decorative flicker without changing hatch time or gameplay.

## Acceptance

Show all 12 identities in a contact sheet. Inspect native size, integer enlargement and the actual phone widget. Verify the binary seed reads as a distinct beginning stage. Every evolution and reaction must resolve without classic fallback art. Test the tallest antenna and longest cable at both movement limits with status effects visible.
