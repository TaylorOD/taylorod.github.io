# Sprint

Included in 2.0. Follow the [shared game rules](README.md).

The [Connection manual](https://www.bandai.com/amfile/file/download/file/242/product/1304058/) describes repeated button presses to race toward the finish.

## Our version

Race a computer opponent over a short course. Tap Run or press Space to advance. Cap accepted taps so rapid hardware repeats do not create an advantage. Choose Steady running before Start for an equally effective option. Its Run steadily button starts running and Stop running stops it.

Start with a three second countdown. The course has 30 steps. Accept at most two steps per second in either mode. The opponent finishes 18 seconds after the countdown, or 20 seconds in slower mode. Reach the finish before the opponent to win. Show a countdown and ignore early input. Use a fixed opponent pace for the selected difficulty.

## Screen and art

Use the current pet in the upper lane and a distinct opponent in the lower lane. Put race progress below the display. Keep the screen still and move the runners, with a visible finish marker. Reduced motion uses fewer pose changes and no scrolling scenery.

## Check it

Test touch, keyboard and hold mode against the same finish threshold. Pause must stop both runners. Check ties explicitly and award a tied finish as a win. Never require uncomfortable tapping speed to finish.

An early tap can queue one step at the next half second boundary. Extra taps cannot stack or beat steady running.
