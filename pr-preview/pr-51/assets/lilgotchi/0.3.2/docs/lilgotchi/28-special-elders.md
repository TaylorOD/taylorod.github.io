# Special elder appearances

Slice gets pale cheese, mold patches and a drooping tip. Cypunk gets a fragmented cyan body with detached magenta pixels. Both retain all six care expressions and fit the existing 12 by 12 sprite allocation. There is no flashing or new motion outside reduced motion controls.

They replace the previous Pizza Chef and Mainframe artwork for the existing oyajitchi identity. Existing saves, names in history, launcher art and reactions pick up the new form through the shared sprite and name maps.

No evolution conditions change. Calzone, Ghost and the Lilgotchi Maskutchi branch become eligible at age 10 and 100% discipline. Each eligible tick has a 5% transition chance. Spoiled Slice is an elder appearance, not a separate illness or neglect mechanic. The character guide explains the adult branch conditions.

Validation includes the shared threshold boundaries, retained mold and glitch details in every expression, all reaction bounds and desktop/mobile browser previews. tests/elder-preview.html seeds isolated local test pets and is excluded from release builds.
