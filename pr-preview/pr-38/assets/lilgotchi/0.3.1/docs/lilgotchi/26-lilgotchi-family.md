# Lilgotchi egg family

Lilgotchi is the logo egg as a playable family. It uses cream, gold and muted green pixels with a cream shell and dark display.

The starting egg is small. Baby adds eyes, child and teen get taller, and adult is a bigger egg. The elder form adds a crack. Adult branches retain the egg body with different expressions, rather than introducing unrelated animals. The elder uses the existing special evolution route, so it is not guaranteed for every pet.

All original care, hatch timing, growth rules, reactions and save protections apply. The new public ID is lilgotchi. It is included in all characters and can be selected in a restricted roster. Existing saves and internal original character IDs remain compatible.

The landing page features Original egg, Slice, Cypunk and Lilgotchi in four columns on desktop and two on mobile. The other original characters stay in the dropdown. Taylor's site uses only these four families.

Tests render every stage and expression, plus 90 animation positions across 15 reactions, checking screen bounds. Browser review covers the landing gallery and the actual new pet on desktop and mobile.
